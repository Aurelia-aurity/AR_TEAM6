# 장구 타격 판정 기준과 조정 방법

[기능 명세 FR-008·009](AR_가상악기_기능명세_표정리.md)는 3D 이동 방향·속도 검사와 중복 타격 방지를 요구한다. 아래 수치는 현재 코드의 초기 설정값이다. 프리뷰에서는 장구 A·B면의 안쪽 원판을 등록한다.

## 타격 기준

1. 채별로 신뢰도가 0보다 큰 추적 위치를 저장한다. 타임스탬프는 유한하고 이전에 수락한 값보다 커야 한다. 추적이 끊기면 이전 위치를 지운다. 유효한 두 샘플의 간격이 100ms를 초과하면 현재 위치를 다음 판정의 시작점으로 삼는다.
2. 채의 월드 위치 차이를 경과 시간(초)으로 나누고, 속도 벡터를 타격면 안쪽 방향으로 투영한다. 이 성분이 최소 속도를 초과해야 한다.
3. 두 채 끝점의 위치를 타격면 로컬 좌표로 변환한다. 타격면은 로컬 Z가 0인 평면이며, +Z는 면 앞쪽이다. 이전 로컬 Z가 양수이고 현재 로컬 Z가 0 이하일 때 선분과 평면의 교차점을 구한다. 교차점의 로컬 XY가 `HitBox2D` 사각형 안에 있으면 타격 후보가 된다.
4. 처음 조건을 만족한 패드에서 해당 채를 잠그고 `OnValidHit`를 한 번 발행한다. 이벤트에는 패드 ID, 채 ID, 월드 교차점, 0~1로 정규화한 `HitForce`가 들어간다. 채 끝점이 친 면의 앞쪽으로 재타격 거리보다 더 물러나면 잠금을 푼다. 잠금을 푼 샘플의 다음 샘플부터 다시 타격을 검사한다.

## 설정값과 조정 방법

| 설정 | 기본값 | 조정 기준 |
| --- | ---: | --- |
| `MinVelocityToTrigger` | 1.5 월드 단위/초 | 느린 접근도 타격으로 잡히면 올린다. 면을 정확히 통과하는 약한 타격이 빠지면 깊이와 좌표 정렬을 확인한 뒤 낮춘다. |
| `MaxVelocityToMap` | 15 월드 단위/초 | 이 속도부터 강도가 100%다. 대부분의 타격이 100%면 올리고, 세게 쳐도 강도가 계속 낮으면 낮춘다. 최소 속도보다 크게 설정한다. |
| `RearmDistance` | 0.3 월드 단위 | 면 근처에서 흔들릴 때 중복 타격이 나면 늘린다. 채를 들어 올려도 연타가 어려우면 줄인다. |
| `MaxTrackingGapMs` | 100ms | 실제 샘플 간격을 기록한 뒤 조정한다. 값을 줄이면 오래 끊긴 경로를 이어 판정하는 경우가 줄고, 간격이 긴 유효 타격도 더 많이 건너뛸 수 있다. |
| `HitBox2D` | 프리뷰에서 안쪽 원판 메시의 너비·높이 사용 | 가장자리 오판정이 있으면 사각형 크기를 바꾸기 전에 `HitSurface`의 위치와 로컬 +Z 방향을 확인한다. |

강도는 최소 속도부터 최대 강도 기준 속도까지 선형으로 정규화한다. `HitSurface`는 패드를 등록할 때 필수이며, 면의 위치와 방향을 설정하는 기준이다.

프리뷰는 양쪽 안쪽 원판의 실제 메시 중심을 비교해 각 면의 바깥쪽을 구하고, 그쪽을 `HitSurface`의 +Z로 설정한다. 장구와 북은 A·B면의 X축 배치가 반대이므로 면 이름만으로 방향을 정하지 않는다. 타격 평면도 메시 두께의 바깥쪽 끝에 둔다.

현재 숫자 설정은 [HitDetectionCore.cs](../unity/ARInstruments/Assets/Performance/Scripts/HitDetectionCore.cs)의 C# 속성이다. 테스트 씬에서만 시험하려면 [DrumHitPreview.cs](../unity/ARInstruments/Assets/Performance/Scripts/DrumHitPreview.cs)의 `new HitDetectionCore()`에 조정할 속성을 지정한다. 프리뷰의 배치 슬라이더는 장구 위치와 회전을 바꾼다.

`DrumHitPreview`는 면 생성, 배치 조절, 채 드래그와 시나리오 재생을 담당하는 공통 기반 컴포넌트다. [JangguHitPreview.cs](../unity/ARInstruments/Assets/Performance/Scripts/JangguHitPreview.cs)는 장구 모델 참조, 영역 ID와 덕·쿵 음원 매핑을 제공한다. 기존 장구 씬의 컴포넌트와 버튼 연결은 유지한다.

## 확인 방법

1. Unity에서 `Assets/Performance/Scenes/JangguHitPreview.unity`를 열고 Play를 실행한다.
2. 각 시나리오의 `L`·`R` 버튼으로 정상 타격 1회, 재타격 2회, 패드 바깥 통과 0회, 타격면 앞에서 정지 0회를 확인한다. 자동 시나리오는 화면에서 천천히 재생하면서 판정에 33ms 간격의 추적 샘플을 전달한다.
3. Game 탭에서 두 십자선을 직접 끌고, 장구를 회전해 A·B면을 각각 확인한다. 채별·면별 타격 횟수와 마지막 강도를 살펴본다.
4. 실제 카메라를 연결한 뒤 채 끝점의 월드 Z, 면에 수직인 거리, 연속 샘플의 시간 간격을 기록한다. 팀원 A의 추적에서 채가 면에 접근하고 물러날 때 Z값과 판정이 일치하는지 검증한 후 수치를 조정한다.

`JangguHitPreviewTests`의 실제 면 위치 테스트는 장구와 북 Prefab을 각각 사용한다. 생성된 타격면 방향 대신 두 메시 중심의 중점에서 각 면으로 향하는 벡터로 채 경로를 만든다. 기본 자세와 Y축 180도 회전, A·B면, 좌우 채에서 진입 1회·면 근처 흔들림과 인출 0회·충분히 물러난 뒤 재진입 1회 및 오디오 소스 재생 수를 확인한다. 북 테스트의 오디오는 장구 프리뷰의 기존 샘플을 사용하며 북 전용 음원 연결을 검증하는 테스트는 아니다.

실제 카메라의 Z 추적 정확도는 아직 검증 전이다. 현재 타격 영역은 두께 없는 직사각형 면이며, 바깥 고리 판정은 후속 작업이다. 안쪽 면의 타격음 재생과 음량·피치 조정은 [장구 타격음 비교 및 튜닝](janggu_audio_preview_ko.md)을 참고한다.
