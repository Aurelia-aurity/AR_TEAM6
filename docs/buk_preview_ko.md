# 북 모델·타격 미리보기

씬: `Assets/Performance/Scenes/BukHitPreview.unity`

북 표시용 `Buk.prefab`을 배치한 독립 프리뷰다. 실제 카메라 입력 없이 모델 자세와 양쪽 안쪽 원판의 타격 판정을 확인한다. 장구 씬과 북 원본 Prefab은 수정하지 않는다.

## 조작

1. 씬을 열고 Play를 실행한다.
2. `Position X/Y/Z`로 기본 위치에서 ±0.4m 이동하고, `Rotation Y`로 ±180도 회전한다.
3. `Scale`로 기본 크기의 0.5~1.5배를 조절한다. 크기 변경 시 공통 타격면을 다시 구성해 판정 영역도 모델 크기에 맞춘다.
4. `Show other face`로 180도 회전해 반대편을 본다. A/B 표시는 각 타격면을 따라 움직이며, 카메라를 향한 쪽으로 채를 재배치한다.
5. L/R 십자선을 잡아 북면 안쪽 원판으로 밀어 넣는다. 좌우 채별·면별 횟수와 마지막 강도를 확인한다. 채를 빼는 동작은 추가 타격으로 세지 않는다.
6. `Reset pose`는 위치·회전·크기를 초기화하고, `Reset mallets`는 채 위치와 타격 카운터를 초기화한다.

## 자동 시나리오

각 행의 L/R 버튼으로 해당 채만 재생한다. 실행 중에는 직접 드래그를 막고, 끝나면 채를 원래 위치로 돌려놓는다.

| 시나리오 | 예상 타격 수 |
| --- | ---: |
| Hit and stay behind | 1 |
| Lift and hit again | 2 |
| Cross outside pad | 0 |
| Stop before face | 0 |

양면 모두 `DrumStrikeSurfaces`와 `InstrumentHitRuntime`을 사용한다. 이벤트 영역 ID는 `buk_head_a_inner`와 `buk_head_b_inner`이며, 판정 대상은 안쪽 원판의 사각형 영역이다. 바깥 가죽·테두리 판정은 포함하지 않는다.

## 음원 비교와 조절

`Assets/Performance/Scenes/BukAudioPreview.unity`를 열고 Play를 실행해 좌고 단음의 `Strong`·`Medium`·`Weak`를 재생한다. 원본 파일은 `Jwago_1.wav`·`Jwago_2.wav`·`Jwago_3.wav` 순서다. A/B면은 같은 세 음원과 설정을 공유한다.

포함된 WAV 사본은 각 파일 최대 진폭의 1%(-40dB)에 처음 도달하는 지점을 기준으로 앞부분을 잘라, 타격 시작을 약 5ms로 맞췄다. 제거한 앞부분은 강 약 422.22ms, 중 약 196.83ms, 약 약 197.89ms다. 파일 시작 약 1ms에만 페이드 인을 적용했고, 그 뒤의 타격음·잔향 샘플과 44.1kHz 스테레오 16비트 PCM 형식은 유지했다. 편집 기준은 피치 1이며 피치를 바꾸면 재생 시 시작 시간도 함께 변한다.

- 각 샘플의 `Gain`(0~5배), `Pitch`(0.5~1.5)를 슬라이더 또는 숫자로 조절한다. 프로젝트에 포함한 프로필의 기본값은 강·중·약 모두 음량 3.9배, 피치 1이다.
- UI는 장구 음원 비교 씬과 같은 정적 Canvas 구조로 저장되어 Play 전에도 배치와 버튼 연결을 편집할 수 있다. 샘플별 음량·피치·재생 행 아래에 Inspector·튜닝창과 같은 A/B 3×3 합타 그리드가 있다.
- `Two-face mix (A + B)`는 행의 A면 강도와 열의 B면 강도를 조합한 9가지 합타를 재생한다. 연타는 기존 잔향을 유지한다. `Stop playback`으로 모든 소리를 중지한다.
- 변경은 세션 복사본에 적용한다. 장구와 같이 `Save tuning on Play Mode exit`는 매 세션 꺼져 있으며, 켠 뒤 Play를 종료했을 때 수정한 음량·피치만 기본 프로필에 저장한다. Editor 튜닝창에서는 `프로필 저장`으로 저장한다.
- Play를 실행하지 않고 비교하려면 `ARInstruments/Audio Tuning/Buk` 메뉴 또는 `BukSoundProfile.asset`의 Inspector를 사용한다. 편집기에서는 강도 조합 9개도 비교할 수 있다. 장구·북의 편집기 미리듣기는 하나의 재생 소유권을 공유한다.
- 공통 감쇠 0.35배와 상한 0.95의 리미터를 사용한다. 런타임 리미터는 같은 AudioListener의 전체 출력에 적용된다. 프리뷰들이 공유하며 마지막 사용자가 닫힐 때 프리뷰가 추가한 리미터만 제거한다.
- 교체 음원이 로딩 중이면 완료 후 재시도 안내를 표시한다. 편집기 PCM 읽기에 부적합한 임포트는 설정 변경을 안내하지만, 읽을 수 있는 `Compressed In Memory + PCM` 조합은 허용한다. 이 편집기 제한은 런타임 재생에 일괄 적용하지 않는다.

`BukHitPreview` 씬의 직접 드래그와 타격 시나리오도 같은 프로필·재생기를 사용한다. 양쪽 모두 강도 0.33 미만은 `Jwago_3`(약), 0.33 이상 0.66 미만은 `Jwago_2`(중), 0.66 이상은 `Jwago_1`(강)을 재생한다. 타격은 1회 재생하고 인출·면 근처 흔들림은 추가 재생하지 않는다. 다른 쪽 면이나 좌우 채의 연타도 이전 잔향을 유지한다. 음원 출처와 이용 조건은 [저작물 이용 고지](../NOTICE.md)를 따른다.

## 씬 관리 및 검증

프리뷰 씬은 저장소에 포함된 파일을 직접 열어 사용하고 Unity Editor에서 편집한다. 별도 생성 스크립트는 사용하지 않는다. 빌드 씬 목록은 변경하지 않는다.

`BukHitPreviewTests`는 A/B면·좌우 채의 네 가지 시나리오, 이동·회전·축소·확대 후 타격, 초기화, 중복 타격면 제거와 면 표시 위치를 검증한다. 실제 카메라 추적과 기기 터치 입력은 별도 확인이 필요하다.

### 음량 3.9배 클리핑 검증

2026-11-26 Unity `6000.6.8f1` Windows Editor에서 강·중·약 모두 음량 3.9배, 피치 1로 검증했다. 공통 감쇠 0.35배를 포함하며, 아래 값은 정규화된 PCM 진폭이다.

| 검사 | 리미터 전 최대 피크 | 리미터 후 최대 피크 |
| --- | ---: | ---: |
| 강 단타 | 0.991133 | 0.950000 |
| 강+강 합타 | 1.982266 | 0.950000 |
| 강+강 10회, 100ms 간격으로 합성 | 2.283692 | 0.950000 |

전체 길이의 단타 3개·합타 9개·연타 PCM을 실제 `JangguPeakLimiter`에 블록 단위로 통과시켰고, 편집기의 합타 WAV 생성 경로도 검사했다. EditMode 관련 테스트 6개가 통과했다. PlayMode 관련 테스트 5개에서는 실제 리스너의 좌우 출력을 측정해 단타·합타·연타 최대 피크가 0.950000 이하이고 무음이 아님을 확인했다. 위 정확한 100ms 간격 검사는 PCM 합성 기준이며, PlayMode 연타 간격은 프레임 진행의 영향을 받는다.

검사 범위에서 ±1을 넘는 샘플 클리핑은 없었다. 합타·연타에서는 리미터 감쇠가 적용되며, 실제 기기의 청감과 오디오 장치의 아날로그 출력은 이 검사에 포함하지 않았다.
